# Code of Conduct

CaptureKit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, respectful and constructive. Harassment, personal attacks,
discriminatory language and publishing others' private information are not tolerated.

## Reporting
Report unacceptable behaviour privately to the maintainers via the contact listed on the
project's GitHub profile (to be added when the repository is published). Reports are
handled confidentially. Maintainers may remove contributions or ban participants who
violate this code.
